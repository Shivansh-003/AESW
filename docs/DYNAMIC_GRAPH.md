# Dynamic Graph Engine

---

## 1. Overview & Research Scope

The Dynamic Graph Engine provides stochastic discrete-time modeling of time-varying edge availability over an underlying static graph:

$$G_t = (V, E_t), \quad E_t \subseteq E$$

where:
- **Static Topology $G = (V, E)$**: Generated by the Graph Generation subsystem; strictly immutable throughout all dynamic time evolution.
- **Active Edge Set $E_t$**: The set of operational, traversable edges at discrete simulation step $t \in \{0, 1, 2, \dots\}$.
- **Dynamic Edge State**: Every underlying edge $e \in E$ possesses a binary state:
  $$s_t(e) \in \{\text{ON}, \text{OFF}\}$$

The Dynamic Graph Engine models environmental dynamics independently from search agents. Walkers and algorithms interact with $G_t$ through controlled interfaces and never dictate or directly observe the underlying transition probabilities $p_{\text{on}}$ and $p_{\text{off}}$.

---

## 2. Mathematical Transition Model

At each discrete time transition $t \to t+1$, each edge transitions independently as a two-state discrete-time Markov chain:

$$\Pr(s_{t+1}(e) = \text{OFF} \mid s_t(e) = \text{ON}) = p_{\text{off}}$$
$$\Pr(s_{t+1}(e) = \text{ON} \mid s_t(e) = \text{OFF}) = p_{\text{on}}$$

Transition Probability Matrix:

$$\mathbf{P} = \begin{pmatrix} 1 - p_{\text{off}} & p_{\text{off}} \\ p_{\text{on}} & 1 - p_{\text{on}} \end{pmatrix}$$

### Synchronous State Updates
Transitions across all edges in $E$ are evaluated synchronously:
1. All edge states at step $t$ are read.
2. Next states at step $t+1$ are computed simultaneously using isolated pseudo-random draws.
3. The new state mapping is committed, and simulation time advances to $t+1$.

This guarantees that edge state updates are order-independent and deterministic.

---

## 3. Initialization Policies

At simulation onset ($t = 0$), edge states are initialized according to one of three policies:

1. **`ALL_ON`**: All edges begin active: $s_0(e) = \text{ON}, \ \forall e \in E$.
2. **`ALL_OFF`**: All edges begin inactive: $s_0(e) = \text{OFF}, \ \forall e \in E$.
3. **`STATIONARY`**: Each edge is sampled independently from the stationary distribution of the Markov chain:
   $$\pi_{\text{ON}} = \frac{p_{\text{on}}}{p_{\text{on}} + p_{\text{off}}}, \quad \pi_{\text{OFF}} = \frac{p_{\text{off}}}{p_{\text{on}} + p_{\text{off}}}$$
   *(If $p_{\text{on}} = p_{\text{off}} = 0$, defaults to `ALL_ON`).*

---

## 4. Dynamic Churn Regimes

To facilitate systematic benchmark comparisons across varying degrees of topological instability, the framework supports five named churn regimes:

| Regime | $p_{\text{on}}$ | $p_{\text{off}}$ | Description |
| :--- | :--- | :--- | :--- |
| **`STATIC`** | $0.0$ | $0.0$ | Purely stationary topology ($G_0 = G_1 = \dots = G_T$). Zero transitions occur. |
| **`SLOW`** | $0.01$ | $0.005$ | Low topological volatility with infrequent link state alterations. |
| **`MEDIUM`** | $0.05$ | $0.025$ | Moderate edge churn representing typical ad-hoc network fluctuations. |
| **`FAST`** | $0.10$ | $0.050$ | High churn rate stressing search agent path-finding resilience. |
| **`VERY_FAST`** | $0.20$ | $0.100$ | Severe edge volatility with frequent disconnections and reformations. |

*Note: Numerical values represent configurable experimental defaults defined in `configs/dynamics.yaml` and can be customized per experiment.*

```text
Static GraphInstance G = (V, E)
             │
             ▼
DynamicGraphState (Markovian Transition Engine)
   ├── time: int (t = 0, 1, 2, ...)

ActiveGraphView G_t = (V, E_t)

   ├── active_neighbors(u) -> list[node_id]
   └── active_degree(u) -> int
```

## 6. Reproducibility & RNG Design

Dynamic trajectories are strictly reproducible through isolated NumPy generator streams:
$$\text{Static Graph} + \text{Dynamics Parameters} + \text{Initialization} + \text{Dynamic Seed} \implies \text{Exact Dynamic Trajectory}$$

- The dynamic engine receives its own isolated `numpy.random.Generator` initialized via `create_rng(seed)`.
- Global random seeds are never modified.
- Decoupled random streams allow independent control over graph generation seeds and dynamic transition seeds for paired experiments.
